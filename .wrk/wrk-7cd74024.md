Acceptance evidence:

- Snapshot movement and empty-cell behavior: the piecewise rule reads source and
  destination from immutable pre-operation state; occupied values overwrite only
  their corresponding layer. A destination hole preserves the pre-move value,
  including when that position is also in the source. Clearing is limited to
  the source outside the destination rectangle. The overlap table explicitly
  yields `A . B C X Y -> . A B B C Y`; a naive clear-all-source algorithm would
  violate the documented hole behavior. Copy/paste/transform share that same
  destination compositing rule; cut is an explicit reversible erase.
- Overlap/undo: the 8x8 house and 3x2 rotation examples state all vacated and
  overwritten cells and complete inverse outcomes. One immutable snapshot drives
  all previews in a gesture, one transaction covers every included layer, and
  history records original destination values. The model rehearsal compared
  complete before/after snapshots across Undo and Redo, not only visible cells.
- Layer identity/offsets: a new selection uses only the active visible layer;
  explicit visible IDs share one rectangle/origin. Membership is pinned despite
  active/name/order changes, while hiding/removing an included layer invalidates
  the whole selection. Clipboard placement uses original IDs in the original
  session. The house rehearsal leaves all 16,384 Terrain cells unchanged, moves
  only W/F, preserves registry IDs and verifies every cell on those two layers.
- Annotation/lifecycle/boundary scope: no annotation record ever enters a payload
  or transform; the house rehearsal preserves complete annotation metadata.
  The contract explicitly covers Escape and cancellation, immediate Cut without
  subsequent Paste, cut-then-cancel (Undo Cut is the recovery), repeated Paste,
  stale layers/registry references, session-bound clipboard and cross-document
  rejection, and full-rectangle boundary rejection including holes. Freeform
  selection and automatic annotation movement remain excluded. Cancellation,
  no-op, stale-plan and capacity failures preserve document/history checkpoints.

Resolved implementation choices include half-open inclusive-drag normalization,
creation-only clipping, full-destination rejection for edits, a top-left-anchored
quarter-turn with swapped dimensions, transparent holes, and a session-local
clipboard with identity mapping. The overlap precedence can retain source content
beneath destination holes; the record deliberately explains this consequence.
Independent committed nudges/turns snapshot the resulting map, so they need not
undo earlier collisions; pure preview payload transforms obey four-turn/two-flip
identity, while exact document recovery uses Undo. These are explicit choices
within the ticket's decision scope, not newly confirmed product requirements.
