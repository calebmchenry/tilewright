Add a simple executable script that processes ready WRK tickets one at a time using Codex with no sandbox or approval prompts. Each Codex call must use the sprint-execute skill, implement and validate its ticket, and mark it done through wrk. Continue until no ready tickets remain, stop on failures or incomplete execution, and distinguish all work complete from blocked unfinished tickets. Document invocation and verify using temporary tickets and a stand-in Codex executable without running the real backlog.

## Implementation

- Added executable scripts/run-tickets.sh using wrk run --ready --expect-status done, with a fresh codex exec --dangerously-bypass-approvals-and-sandbox call per ticket.
- Prompt explicitly invokes sprint-execute, selects Strategy A for unattended execution, treats the ticket as the sprint document, and uses WRK for progress, validation evidence, and completion.
- Checks prerequisites and the skill path; permits SPRINT_EXECUTE_SKILL override. Final active-ticket check reports blocked/in-progress work instead of claiming completion.
- Added usage and restart instructions in README.md and ignored generated .wrk-runs/ logs.
