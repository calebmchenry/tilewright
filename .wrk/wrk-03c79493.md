## Outcome

Remove the 8 CSS-pixel-per-tile restriction for Pencil and Eraser so large brushes remain usable while zoomed out, including Fit and cached overview rendering.

## Source and scope

User feedback, 2026-11-19: large pencil brushes are not usable because zooming out disables the pencil; backtrack on that requirement. Pencil and Eraser share square-brush behavior and should both work at every supported zoom. Other tile tools retain their existing detail threshold.

## Acceptance criteria

- [x] Pencil/Eraser toolbar actions, shortcuts, hover and pointer strokes work below the old threshold.
- [x] Zoomed-out strokes preserve exact footprints, layer isolation, fixed bounds, one-step undo/redo and existing readiness/cancellation protections.
- [x] Overview messaging and current requirements describe the revised behavior.
- [x] Domain and browser regressions cover detail/overview transitions and cached overview painting/erasure.

## Validation

Record implementation and functional validation before completion. Rendering/presentation performance remains TW-049; large edit/history/memory refinement remains TW-050. No new performance-budget pass is required or claimed.
