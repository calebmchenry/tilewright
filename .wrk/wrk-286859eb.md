## Outcome

Reorient rectangular tile content with predictable geometry and reversible overwrites.

## Source and scope

**Source:** INTENT.md — Drawing and rearranging; INTENT.md — First-version success criteria.

**Execution order:** 27 of 54. Phase: selection.

**Prerequisite:** [wrk-54aa1866](wrk-54aa1866.md) — TW-026: Implement cut, copy, paste, and repeated selection placement.

This is an intentionally sequential delivery backlog. The dependency includes earlier prerequisites transitively; complete it before starting this ticket.

Implementation details left open by INTENT.md are decisions to document, not additional confirmed user requirements.

## Work

- Implement quarter-turn rotation in the supported directions plus horizontal and vertical reflection.
- Transform all included layer payloads with the same pivot and relative offsets; update selection bounds for non-square rotations.
- Apply boundary, destination compositing, preview, and history rules consistently with movement/paste.

## Acceptance criteria

- [ ] Rotating a non-square selection swaps dimensions and maps every occupied cell and hole correctly.
- [ ] Four quarter-turns and two identical flips recover the original payload; registry references remain unchanged.
- [ ] Transforms affect only included layers and never transform named areas or labels.
- [ ] Undo restores both transformed source content and overwritten destinations; cancellation/out-of-bounds failures leave state untouched.

## Validation

- Test asymmetric, non-square, single-row/column, sparse, overlapping, and edge-adjacent selections.
- Inspect a multilayer house after rotation and each flip, then undo the entire sequence.

Record the implementation/decision location and actual validation evidence in this ticket before marking it done.
