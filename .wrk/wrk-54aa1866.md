Reuse rectangular content while preserving layers, colors, and registered meaning.

## Work

- Implement clipboard payloads and cut/copy/paste actions using the documented clipboard and layer-mapping policy.
- Provide a paste preview/anchor and clear commit/cancel behavior, including repeated paste.
- Preserve source registry identities and handle cross-document or stale-layer references according to the contract.

## Acceptance criteria

- [x] Copy leaves document/history unchanged; cut removes only included-layer cells with a reversible command.
- [x] Paste preserves relative geometry, separate layers, raw colors, and registry associations.
- [x] Empty-cell and collision behavior follows the contract; overwritten destination data is restored by undo.
- [x] Clipboard operations contain no annotations, obey fixed bounds, and do not override text-field cut/copy/paste.

## Validation

- Test cut then cancel paste, repeated paste, layer removal after copy, boundaries, and any supported cross-document case.
- Copy a layered house, paste it, recolor its registry entry, and verify both copies update correctly.

Acceptance audit:

1. Copy preserves complete content, version, history, redo and saved/recovery
   checkpoints. Captures are frozen and remain independent of source edits.
   Cut clears occupied cells only in included W/F layers in one reversible Cut
   command, preserving Terrain, bounds and annotations. Cut then no paste,
   rejected paste or Escape stays cut until Undo. Failed Cut retains the previous
   clipboard; empty Cut/Paste and identical repeated Paste add no history.
2. Layered 8x8 house capture/paste preserves common geometry, separate W/F layers,
   exact raw bytes (including alpha zero), and stone registry IDs. Full-cell
   oracles compare overlapping, nonoverlapping and signed-coordinate placements
   against the original map; exact Undo/Redo restores overwritten destinations.
   Recolor through the actual registry Edit dialog updates original/pasted stone
   pixels together, while raw cells matching its old shade remain unchanged.
3. Sparse holes emit no writes, so destination cells under holes survive, including
   the red furniture cell at (70,66). Preview and commit never clear the copy's
   source. Failed history-capacity operations roll back all layers; no-op
   placement preserves redo/checkpoints. Clipboard dependency checks include
   empty layers, hidden/removed layers and removed/malformed registry entries.
   Rename/order/active-layer changes never remap; original IDs restored by Undo
   permit retry. Cross-document/session paste is explicitly unsupported and
   rejected, including another session over the same model object. New Map drops
   the old session clipboard.
4. Payloads contain no annotations; exact annotation records remain unchanged.
   All four edges, signed corners, exact touching, all-hole extents and unsafe
   coordinate arithmetic are checked without clipping or automatic growth.
   Invalid paste stays adjustable; Escape restores prior selection. Native text
   input/contenteditable cut/copy/paste succeeds without map edits, and text,
   panel, IME and modified-key guards are covered. Window blur, capture loss,
   pointer cancel, navigation, context changes, mutation and disposal drop previews.
